Zalo delivery (global)

One Zalo identity for the whole company. Tokens live in zalo_config.json (outside the profile, never committed to git). Pick the provider, then fill in the matching credentials.

A bot can only message a chat that already exists, so a tenant who has never opened the bot cannot receive a bot message at all. ZBS Template Message is the only channel that reaches someone who has not interacted with you: it is addressed by phone number, needs a Zalo-approved template id and is billed per message. Leave the fallback off until you have an OA access token and an approved template.
